# 設計と旧版からの継承

- 静的 HTML / CSS / ES Modules。ビルド不要。GitHub Pages のリポジトリ配下に対応する相対パス。
- courses.json は選択画面用の小さな目録。作品 JSON は選択時、地理背景は地図画面を初めて開くときに取得。
- 各作品は points（実際の旅程の代表地点・再訪を区別するID）、readings（本文の読書順）、images、sources を持つ。読み物は pointId で解放地点と結ぶ。本文の叙述順と旅程順を混同しない。
- 現代語化は既存の膝栗毛56篇を引き継ぐ。旧版で便宜上石薬師以西に置いた伊勢・京都・大坂の話は原作の舞台へ移す。
- 記録の距離は整数メートル、累計は履歴の和。仮想進捗だけ終点で止める。読了は歩行達成と独立し、記録削除でも消さない。
- storage.js は新しい保存領域 aruku-nihon-kiko-v2 を使用。旧 aruku-tokaido-v1 は書き換えず膝栗毛へ一度だけコピー。異なるURL/ブラウザ間では旧版のJSONを書き出して読み込む。
- 元の歩行距離をそのまま継承し、新ルートに再配置。旅程変更により旧版と現在地・踏破率は変わる。
- 背景は47都道府県の海岸線・境界を同梱するSVG地図。地図タイル配信障害で背景が消えない。代表地点を結ぶ概略線であり、現地ナビではない。
- 距離は歴史的実測と断定しない。膝栗毛の既存東海道区間以外は代表座標から計算した換算距離。芭蕉は全旅約2400kmの目安に配分した歩行用距離。各作品の distanceNote に算定方法を表示。
- 画像は重複を避けてWebPへ外出し。作者・出典・ライセンス・種別・加工内容を画像データで管理。原作挿絵、風景画、現在の写真、現代の人物イラストを明記。
- 外部情報をHTMLとして挿入しない。インポートは日付・距離・ID等を検証してから保存。
