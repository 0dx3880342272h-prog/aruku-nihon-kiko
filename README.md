# 歩く東海道五十三次 ― 弥次喜多道中

GitHub Pages向け分割版です。

## GitHubへアップロードするファイル
このフォルダ内の次の6ファイルを、リポジトリの一番上（root）へ同じ階層でアップロードしてください。

- index.html
- style.css
- data.js
- art.js
- book.js
- app.js

`index.html` だけをアップロードしても画像や機能は動きません。6ファイルすべて必要です。

## GitHub Pages
リポジトリの Settings → Pages → Deploy from a branch → main / (root) を選んで保存します。
