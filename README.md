# 歩く日本紀行 2.1

日々の歩行距離を、文学作品の旅へ。静的HTML/CSS/JavaScriptで動く、スマートフォン向けウォーキング・読書アプリです。

## 2.1の更新内容

- 膝栗毛68地点・おくのほそ道82地点、全150地点に画像を対応。新たに83点を追加しました。
- 指定の人物画像へ変更：膝栗毛は庶民風の2人、おくのほそ道は僧侶風の2人。左向き・右から左への移動を維持。
- 地点一覧・地図の選択カード・読書画面でも地点画像を表示します。
- 現地そのものが確認できなかった画像は「地域の参考」と明記。対応表は `docs/PLACE_IMAGES.md`。
- 歩行記録の保存方式、地点距離、本文・句は2.0から変更していません。

## 収録コース

- **東海道中膝栗毛**：68地点、58篇。旧版56篇を引き継ぎ、伊勢・京都・大坂の本来の舞台へ再配置。日永追分から伊勢へ分岐し、伏見の舟の乗り違えによる往復、住吉から大坂へ帰る結びも収録。
- **おくのほそ道**：82地点、44章、63句の解説。冒頭から大垣まで原文を収録し、独自の現代語抄訳を付けています。本文の章順と実際の主な訪問順を分け、山中→那谷寺→小松再訪などを反映。

膝栗毛は正編から選んだ場面の読書集です。全場面・続膝栗毛を逐語訳した全集ではありません。おくのほそ道の現代語は抄訳で、原文の長い列挙や故事等を省略した箇所があります。「完読」はアプリの収録篇にすべて読了印を付けた状態です。

## GitHub Pagesへ置く

1. 旧版の「記録」からJSONを書き出して保存してください。
2. このフォルダの**中身**（index.html、css、js、data、images、sw.jsなど）を、既存リポジトリの公開対象フォルダへ配置します。フォルダ構成を保ってください。
3. GitHub Pagesの公開元がリポジトリ直下なら直下へ、`docs`ならその中へ置きます。ビルドは不要です。`.nojekyll`も同梱しています。
4. 公開処理が終わったら、ブラウザでそのURLを開きます。古い画面が残る場合は一度再読み込みして、開いている他のタブも閉じてから開き直してください。
5. 「旅の設定」からJSONを読み込み、旧記録を引き継げたことを確認します。

**HTMLを端末で直接開く方式ではありません。** 分割したJSONを読み込むため、HTTPSの公開先またはローカルWebサーバーで開きます。PCで試すなら、このフォルダで `python -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。

既存の巨大な `art.js`・`data.js` 等はこの版では参照しません。公開先の旧版ファイルを整理する場合も、先にバックアップしてください。本納品物は既存リポジトリを変更・公開したものではありません。

## 毎日の使い方

- 起動時の本棚で作品を選びます。記録・累計・読了は作品ごとに独立しています。
- 「旅」の「今日の歩きを記す」、または「記録」から日付とkmを入力します。小数3桁（1m）まで保存できます。
- 「地図」は指で移動、2本指や＋−で拡大。地点をタップ、または選択欄から本文へ進みます。
- 「読む」は原文、現代語、句、解説、画像、出典。検索、未読絞り込み、文字サイズ、読了して次へに対応。
- 未到達の本文は設定の「先読み」で読めます。歩いたことだけで自動的に読了にはしません。
- 履歴は修正・削除できます。累計と現在地を再計算します。読了印は残ります。
- 設定で、選択中の作品の本文・画像・地図をオフライン用に保存できます。外部の出典・高精細画像リンクには通信が必要です。

## 記録の引き継ぎと保存

旧版のキー `aruku-tokaido-v1` を書き換えず、新しい `aruku-nihon-kiko-v2` にコピーします。同じオリジン・ブラウザで旧記録が見つかった初回のみ自動移行します。古いHTMLファイル・別URL・別端末からはJSONで移してください。

- 旧版のメートル数をそのまま保持し、膝栗毛へ移行します。旅程が変わったため、現在地と踏破率は旧版とは異なります。
- JSONの「追加」は同じIDを重複追加しません。同じIDで中身が違う場合は拒否します。
- 旧形式の「置換」は膝栗毛だけ、新形式の「置換」は全コースが対象。実行前に確認画面を出します。
- 読了印を含む全コースを書き出せます。別端末との自動同期・サーバー保存はありません。
- ブラウザのデータ削除で記録が失われます。定期的にJSONを保存してください。保存が失敗した場合は画面に警告を表示します。

## 距離・地図の意味

- 膝栗毛の753.7kmは**歩行用の概算換算値**。日本橋〜四日市は旧版の宿村大概帳換算値を継承。以後は代表点間の球面距離×1.25で配分しています。舟の区間・往復も含みます。
- おくのほそ道は大垣市資料の全旅約2400kmを採用し、収録代表点間の球面距離比で区間へ配分。各区間を歴史的実測距離とするものではありません。
- 地図は47都道府県の海岸線・県境を同梱しています。現在地は区間の距離割合で補間した仮想位置。道筋は代表点を結ぶ概略で、現地のGPSナビではありません。
- 膝栗毛の伊勢〜大和〜宇治は原文が省略する区間で、詳細な道筋は未確定です。大和の点は地域を表すもので、特定の寺院・奈良市街の訪問を断定していません。
- おくのほそ道は日々の全立寄りを網羅した旧道復元ではありません。作品の文学的構成と、曽良の日記などから分かる旅程の差は各地点に注記しています。
- 進捗帯の人物は左向き。出発を右、終着を左に置きます。地理上の北上・南下・折返しは地図で示します。芭蕉の人物は現代のイメージ図で、山中以後の曽良の別行動は本文・地点で明記しています。
